# Text

Preset typography component that maps semantic HTML tags to Material Design 3 type scales.

## Usage

```jsx
import { Text } from 'muir';

<Text type="h1">Page Title</Text>
<Text type="body">Some paragraph content.</Text>
```

## Behavior

| Type | HTML Tag | Typographic Scale | Default Size |
| ---- | -------- | ----------------- | ------------ |
| `h1` | `<h1>` | headline | large |
| `h2` | `<h2>` | headline | medium |
| `h3` | `<h3>` | headline | small |
| `h4` | `<h4>` | title | large |
| `h5` | `<h5>` | title | medium |
| `h6` | `<h6>` | title | small |
| `body` | `<p>` | body | medium |
| `label` | `<label>` | label | medium |
| `title` | `<span>` | title | medium |
| `display` | `<span>` | display | medium |
| `anchor` | `<a>` | body | medium |

## API

The available HTML attributes depend on the `type` prop (discriminated union).

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `type` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6' \| 'body' \| 'label' \| 'title' \| 'display' \| 'anchor'` | **required** | Controls the HTML tag and typography scale |
| `size` | `'small' \| 'medium' \| 'large'` | *scale-specific* | Overrides the default size for the chosen type |
| `children` | `ReactNode` | `undefined` | Content to render |
| `htmlFor` | `string` | `undefined` | For `type="label"`, associates the label with a form element |
| `href` | `string` | `undefined` | For `type="anchor"`, the link destination |
| `target` | `string` | `undefined` | For `type="anchor"`, the link target |

## Customization

Override these variables on the Text root to customize appearance.

| Variable | Default | Description |
| -------- | ------- | ----------- |
| `--font-family` | `var(--md-ref-typeface-plain)` | Font family |
| `--font-size` | `inherit` | Font size |
| `--font-weight` | `inherit` | Font weight |
| `--line-height` | `inherit` | Line height |
| `--color` | `inherit` | Text color |
| `--anchor-color` | `var(--md-sys-color-primary)` | Color for `type="anchor"` |
| `--anchor-visited-color` | `var(--md-sys-color-tertiary)` | Visited link color |
| `--anchor-transition-duration` | `var(--md-sys-motion-duration-fast)` | Transition duration for anchor color changes |
| `--anchor-transition-easing` | `var(--md-sys-motion-easing-standard)` | Transition easing for anchor color changes |
