# Icon

The `Icon` component renders an SVG symbol reference as a square icon. It uses the `<use>` element to reference symbols defined in an SVG sprite sheet, making it efficient and cacheable.

<div style={{ display: 'flex', gap: '16px', alignItems: 'center' }}>
  <Icon name="home" size={24} />
  <Icon name="search" size={24} />
  <Icon name="settings" size={24} />
  <Icon name="favorite" size={24} />
  <Icon name="arrow-forward" size={24} />
</div>

## Usage

```jsx
import { Icon } from 'cuil';

<Icon name="home" />
<Icon name="search" size={32} />
```

The `name` prop references the ID of an SVG `<symbol>` element defined in the sprite sheet.

## Sizes

The icon is always square. Control the size with the `size` prop (in pixels).

<div style={{ display: 'flex', gap: '16px', alignItems: 'center' }}>
  <Icon name="home" size={16} />
  <Icon name="home" size={24} />
  <Icon name="home" size={32} />
  <Icon name="home" size={48} />
</div>

## Coloring

The icon inherits `currentColor`, so it can be styled via the parent's `color` property.

<div style={{ display: 'flex', gap: '16px', alignItems: 'center' }}>
  <span style={{ color: 'var(--md-sys-color-primary)' }}><Icon name="favorite" size={24} /></span>
  <span style={{ color: 'var(--md-sys-color-error)' }}><Icon name="favorite" size={24} /></span>
  <span style={{ color: 'var(--md-sys-color-tertiary)' }}><Icon name="favorite" size={24} /></span>
</div>

## API

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `name` | `string` | — | The name of the SVG symbol to display. |
| `size` | `number` | `24` | The size of the icon in pixels. The icon is always square. |
