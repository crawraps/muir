# smart-clsx

The `createSmartClsx` utility function allow you to create a wrapper around `clsx` that provides CSS Modules support.
The `createSmartClsx` function takes a CSS Module object as an argument and returns a "smart" `clsx` function that's scoped to CSS Module object.

The smart-clsx function works like the default clsx, except that the very first argument of the function will be mapped to the CSS Module object.

## Usage

```tsx
import { createSmartClsx } from 'cuil'
import styles from './style.module.css'

const clsx = createSmartClsx(styles)

// The first argument maps to modular classes in `styles`
// All subsequent arguments are mapped as global classes
const className = clsx(['my-modular-class', { 'modular-active': isActive }], 'my-global-class')
```
